Tre isolerte mobilmockups for issue #112. Åpne hver side på telefon eller smal nettleservindu (~390px). Krysset av-varer bruker rød «ferdig»-stil som i appen i dag.

A — Soft Pastel Calm

Lavendel, fersken og mint. Rolig gradient og myke flater — mindre stress, fortsatt oversiktlig.

Lys base, mye luft, pastell kun på det som teller (fremdrift, fokus). Lesbarhet først.
